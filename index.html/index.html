Правила честной жеребьёвки

  • Один участник не может получить две роли в течение одной недели.
  • Одна и та же роль не повторяется у участника, пока остальные не пройдут эту роль.
  • После полного круга история по роли автоматически открывает новый цикл.
  • Данные сохраняются в localStorage и не теряются после закрытия страницы.
